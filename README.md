# Алгоритм Дейкстри: найкоротші шляхи між містами України (лаб. 5)

- `python main.py` - GUI (граф 29 міст / 50 доріг з таблиці 1 завдання, маршрут за замовчуванням Львів → Кропивницький)
- `python experiments.py` - дослідження (видалення/додавання ребер і вершин, BFS vs Дейкстра) + перевірки коректності
- `python graph.py` - перегенерувати `data/ukraine.json`
- `structure/flowchart.png` - блок-схема алгоритму

Файли: `graph.py` - граф (вершини з координатами схеми, списки суміжності з км); `dijkstra.py` - Дейкстра і пошук
у ширину як генератори подій; `graph_view.py`, `main_window.py`, `results_window.py`, `animation.py` - інтерфейс.

## Редагування графу

ПКМ на порожньому місці - додати місто; ПКМ на місті - звідки/куди, з'єднати дорогою, видалити; ПКМ на дорозі -
змінити віддаль, видалити. ЛКМ - перетягнути місто, подвійний клік по дорозі - змінити віддаль. Кнопки
"Додати місто…", "Дорога…", "Видалити місто…" роблять те саме через діалоги. Віддаль має бути > 0.

## Візуалізація

Біла вершина - не досягнута, жовта - тимчасова мітка (у черзі), зелена - постійна, оранжева - поточна ітерація.
Біля міста - мітка d (✓ = постійна). Зелені лінії - дерево найкоротших шляхів, оранжевий пунктир - prev тимчасових
міток, темно-оранжеві - релаксовані на цьому кроці ребра, синя - шлях. Праворуч - таблиця міток і вміст черги.

## Модифікація пошуку в ширину

| | пошук у ширину | Дейкстра |
|---|---|---|
| черга | FIFO | з пріоритетом за d (heapq) |
| мітка | кількість ребер, остаточна при першому досягненні | сума км, тимчасова, зменшується релаксацією |
| остаточна | при досягненні | коли вершину вибрано з черги |
| кінець | ціль отримала мітку | ціль вибрано з черги |
| шлях | за спаданням міток | за prev[] |

При одиничних вагах Дейкстра = BFS (перевіряє `experiments.py`).

## Результати (`experiments.py`)

Львів → Кропивницький: Львів → Тернопіль → Хмельницький → Вінниця → Кропивницький, **678 км**, 12 ітерацій з 29.
Видалення ребер шляху: +140 / +166 / +168 / +447 км (Вінниця–Кропивницький критичне, обхід через Київ і Полтаву);
усі три дороги до Кропивницького - шлях не знайдено. Видалення Вінниці - 1125 км. Додавання Черкаси–Кропивницький
(130) або Умані основний шлях не змінює, але без Вінниця–Кропивницький дає 829 / 684 км замість 1125.
BFS: 864 км через Чернівці; на всіх парах BFS довший у 300 з 812 (37 %), до +742 км.
